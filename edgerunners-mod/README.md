# Сборка
1. JDK 21. Открой папку в IntelliJ IDEA (Import Gradle project) либо `gradle wrapper` и затем `./gradlew build`.
2. Запуск клиента: `./gradlew runClient`. Готовый jar: build/libs/.
3. В игре: вкладка Cyberpunk: Edgerunners (креатив) — Сэндевистан, Усиленные сухожилия, Подкожная броня.

# Управление
- **B** — меню киберваров (стиль Cyberpunk 2077). Клавиша меняется в настройках.
  - ЛКМ по слоту — выбрать: откроется окно со списком подходящих имплантов из инвентаря (установить) или с информацией об импланте (снять).
  - ПКМ по занятому слоту — снять имплант (вернётся в инвентарь).
  - ESC — закрыть окно / меню.
- **ПКМ предметом-имплантом** — быстрая установка в первую свободную позицию его категории.
- **V** — активировать Сэндевистан (нужен установленный в слот Operating System).

Модель для Blockbench: blockbench/sandevistan.bbmodel
