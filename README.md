# Cyberpunk

**Cyberpunk Edgerunners** Minecraft mod (v0.3)

Source from `edgerunners-mod-v0_3.zip`.

## Folder
All mod files are under [`edgerunners-mod/`](edgerunners-mod/).

## Build
- JDK **21**
- NeoForge `21.1.172`
- `./gradlew build` → jar in `build/libs/`

## Controls (in-game)
- **B** — cyberware menu
- **V** — activate Sandevistan (needs OS implant)
- Right-click implant item — quick install

Creative tab: **Cyberpunk: Edgerunners**
